The states

Working

Soft cyan breathing around the edge — slow, alive, easy to ignore. You know it's thinking without looking away.

breathe · 3.8s

Needs you

Warms to amber and quickens. The one state that earns your attention: an agent is blocked on a decision.

pulse · 1.5s · toast

Done

A single green flash that settles back to calm. Satisfying, brief, then gone — no badge to dismiss later.

flash · one-shot

Error

Red, sharper cadence. Something failed and wants eyes. Distinct enough from “needs you” to read across the room.

pulse · 1.1s

Why it's different

The blind spot in multi-agent work

Omarchy already shows agent usage and limits (omarchy.agents). What it can't tell you is the thing that actually costs you time when you run several agents at once: which one is silently waiting for you.

Ambient Agent answers that through the room, not through a notification tray. The bar orbs scale to N agents; the edge shows the most urgent state:

needs you › error › working › done › idle

How it works

One file. One overlay.

  • 1Your agent (or any command) writes one word — working, needs, done — to a tiny state file.
  • 2A Quickshell layer-shell overlay watches that file and paints the edge glow. Transparent, click-through, zero input capture.
  • 3No daemon, no dependencies beyond the Omarchy shell. Drive it from a hook or wrap a command.
agent-ambient working
npm run build
agent-ambient done

Make it yours

Configurable, hot-reloaded

Edit ~/.config/omarchy/ambient-agent.json — colors to match your theme, calmer glow, slower breathing, or off entirely. No restart.

{
  "colors": { "working": "#7dcfff", "needs": "#e0af68", "done": "#9ece6a", "error": "#f7768e" },
  "glowWidth": 26, "glowOpacity": 0.40, "borderWidth": 3,
  "periods": { "working": 3800, "needs": 1500 },
  "enabled": true
}
